One model, one claim. Zero GPU idle tax by default.

Each self-hosted model is declared as a single Crossplane InferenceService claim—expanding into a vLLM Deployment, shared weights PVC, KEDA ScaledObject, CiliumNetworkPolicy, and Envoy route.

Full claim reference →
apps/base/ai/llm/qwen-coder-fim.yaml 
apiVersion: cloud.ogenki.io/v1alpha1
kind: InferenceService
metadata:
  name: xplane-qwen-coder-fim
  namespace: llm
spec:
  model:
    repository: Qwen/Qwen2.5-Coder-1.5B
    revision: df3ce67c0e24480f20468b6ef2894622d69eb73b
    quantization: fp8
    contextWindow: 8192
  gpu: { count: 1, minVRAM: 8Gi }
  routing: { tier: small, specialty: code-fim }
  scaling: { minReplicas: 1, maxReplicas: 1 }
  cache: { prefixCache: { enabled: true } }

Three independent opt-in gates for GPUs

  1. Cloud storage gate: TM_LLM_PLATFORM_ENABLED=true provisions S3 Files / GCS weights storage and IAM.
  2. Gateway gate: ai-gateway runs CPU-only Envoy AI Gateway and frontier routes.
  3. GPU gate: flux resume kustomization llm-platform enables Karpenter L4 nodes and vLLM claims.
